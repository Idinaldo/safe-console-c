# Safe Console - C

## Sobre

<p>Safe Console - C é uma atividade avaliativa proposta na primeira unidade da cadeira <strong>Algoritmo e Estruturas de Dados</strong>.</p>
<p>O objetivo é construir uma aplicação de console que disponibilize algumas ferramentas introdutórias de cybersegurança, como validador de senhas, encriptador e gerenciador de logs.</p>

## Utilizando o app

Para rodar a aplicação, basta ter o compilador `gcc`. Com ele pronto, rode os seguintes comandos:

```bash
gcc safe.c general.c modone.c -o app
./app
```
